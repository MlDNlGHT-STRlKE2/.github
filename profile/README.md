## 🛠️ Troubleshooting

### Midnight does not start

Make sure Windows is updated and verify that the installed version is compatible with your current CS2 build.

### Settings are not saved

Check that the application has permission to write its configuration files and try creating a new profile.

### The interface does not appear

Restart CS2 and Midnight and check whether another overlay or background application is interfering with the interface.

### Performance changes after a CS2 update

Game updates can change compatibility with external utilities. Check whether a newer Midnight version is available for the current CS2 build.

### Configuration behaves unexpectedly

Create a new profile and test the available settings individually. This can help identify a conflicting configuration option.
